## Selected internal implementation interfaces (not new public APIs)

The dispatch supplies these ordinary implementation-selected seams; tests do not invent a test-only application hook. Production must never import tests. If a seam is infeasible or another private choice is required, return it through coordination before changing tests or normative semantics.

- Existing `createLocalClient({port,token,timeoutMs})` in `src/http/local-client.js`: `request(method,path,body,extraHeaders={},options={signal?})` resolves existing `{status,body}`. Preserve fixed-loopback, protected Bearer, no redirects/proxies, existing errors. Pre-abort opens no request/socket; in-flight abort destroys actual `ClientRequest`/associated transport, settles work and removes its abort listener; post-settlement abort is no-op. No new public error vocabulary imposed by transport tests.
- New `src/mcp/registration.js`: exports `REGISTRATION_HEARTBEAT_MS=10000`, `REGISTRATION_SHUTDOWN_BUDGET_MS=2000`, `REGISTRATION_HEADER='X-Proceed-Registration'`, `RegistrationError(code,message,{retryable=false}={})`, `createRegistrationBinding({client,heartbeatMs,shutdownBudgetMs,logger}={}) -> {ensure,close}`. `ensure()` asynchronously returns private `{registration_id,registration_secret}`. `close()` is awaitable, terminal/idempotent, with one shared budget. Small constructor cadences/budgets are unit inputs only, not public product options.
- `ensure()` is lazy/single-flight. Adopt only valid HTTP 201 authority under the existing patterns. Invalid successes produce `BROKER_UNAVAILABLE`, no timer or release with guessed authority. Duplicate `409/OWNER_IN_USE` never steals/retries/deletes. Preserve recognized versioned broker errors with string message and boolean retryable; unknown/malformed/transport/aborted replies map to redacted `BROKER_UNAVAILABLE`, retryable true. Never invent `BROKER_REJECTED`.
- Heartbeats use empty JSON and require 204. A 401 invalidates old authority and allows one single-flight replacement; transport failure retains known authority. Generation fencing prevents stale create/heartbeat results after close from installing authority, renewing timers, starting work or deleting replacement authority. Close aborts tracked lifecycle work, releases only captured valid authority and aborts a stalled release within the same budget; unknown remote create expires naturally, not guessed release. Timers must not keep process alive (public process-exit gate follows later).
- Optional pattern sharing: add `REGISTRATION_ID_PATTERN` and `REGISTRATION_SECRET_PATTERN` to `values.js`; broker import/re-export preserves U2a exports and encodings. This is not permission to change registry semantics.
