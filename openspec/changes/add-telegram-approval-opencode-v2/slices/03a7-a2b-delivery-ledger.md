- Implement EXACT design4 `request.acknowledge` and `request.returned` mutation fields and array-order replay. Ack sets confirmed/clears error without fabricating returned time. Returned retains confirmed iff already confirmed, otherwise sets returned/clears error. First timestamps are independent, each bounded only by resolution. Preserve exact decoded closure instant for comparisons; avoid millisecond rounding or lexical comparisons. Private field placement/absence representation remains implementation-owned.
- Whole-history staging rejects malformed fields/types/UTC, unknown/pending targets, mismatched decision, wrong state, pre-resolution evidence and duplicate historical same-kind mutations, including identical ones. Retain installed state and bytes; first recovery failure admits no writes. Actual failed append/sync fences all queued/fresh writers and deadline observations; ordinary close/Journal reopen/whole-history replay alone reconciles, never append retries or in-place recovery clearing.

No current blocked/error producer exists: verify clearing assignments by source contract review, not fabricated workflow/state injection. Null error is asserted on ordinary producer paths; positive non-null-error clearing remains a future affected producer obligation.
