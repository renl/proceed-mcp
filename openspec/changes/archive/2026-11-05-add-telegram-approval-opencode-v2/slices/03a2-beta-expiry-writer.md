Empty/terminal-only work uses no clock/ID/append. Install each whole group after successful flush; earlier flushed groups survive later failure. Failure rejects, never returns a misleading partial success count. Request order within groups is not asserted.
- `status() -> Promise<existing status shape>`: serialize expiry AND copied response capture coherently, preserving `{schema_version:1,broker:{pid,port,started_at},requests:[common views]}`.
